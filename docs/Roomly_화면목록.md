# Roomly 화면 목록

---

## 페이지 구조 개요

```
/
├── /                       랜딩 페이지 (T-050)
├── /signup                 호텔 셀프서브 가입 (T-028)
├── /login                  관리자 로그인
├── /reset-password         비밀번호 재설정 (T-055)
├── /guest                  게스트(일일알바) 접속 코드 입력 (?h={hotelId} 파라미터 필수)
├── /terms, /privacy        이용약관 / 개인정보처리방침 (T-180/181)
├── /admin                  전체 객실 현황판 (메인)
│   ├── /admin/rooms        객실 추가·관리
│   ├── /admin/staff        직원 관리
│   ├── /admin/stats        통계 (주간/월간 차트, CSV)
│   ├── /admin/billing      결제·구독 관리 (Toss, T-021)
│   ├── /admin/supplies     비품 재고 현황 (T-122)
│   ├── /admin/maintenance  유지보수 신고 처리 (T-132)
│   ├── /admin/settings     일반 설정·API 키·PMS 웹훅·계정 탈퇴 (T-058/140/182)
│   └── /admin/onboarding   가입 직후 3단계 가이드 (T-052)
├── /worker/[staffId]       고정 직원 화면 (QR 접속, 다국어 ko/en/vi)
├── /worker/dirty/[staffId] Dirty Worker 전용 현황판 (T-017)
├── /worker/guest           게스트 작업 화면
├── /super-admin            운영자 대시보드 (별도 인증, T-060)
├── /org/[orgId]            체인 호텔 멀티 프로퍼티 현황판 (T-151)
└── /offline                PWA 오프라인 폴백
```

### 접근 권한 요약

| 경로 | 권한 | 인증 방식 |
|---|---|---|
| `/`, `/signup`, `/login`, `/reset-password`, `/terms`, `/privacy`, `/guest` | 공개 | — |
| `/admin/*` | 관리자 | Supabase Auth 세션 (미들웨어에서 플랜 만료 체크) |
| `/worker/[staffId]`, `/worker/dirty/[staffId]` | 해당 직원 | `roomly_worker_session` JWT (staffId 일치 검증) |
| `/worker/guest` | 게스트 | `roomly_guest_session` JWT (당일 자정 만료) |
| `/super-admin` | 운영자 | SHA-256 비밀번호 (일반 관리자와 분리) |
| `/org/[orgId]` | 법인 관리자 | Supabase Auth + org_admin 역할 |

## 1. 로그인 — `/login`

**접근 권한**: 누구나 (비로그인)  
**역할**: 관리자 인증 진입점

### 구성 요소
- 호텔 로고 / 서비스명
- 이메일 입력 필드
- 비밀번호 입력 필드
- 로그인 버튼
- 로그인 실패 에러 메시지

### 동작
- 로그인 성공 → `/admin` 이동
- 이미 로그인 상태 → 자동으로 `/admin` 리다이렉트
- 하단 "일일 근무자 입장 →" 링크 → `/guest`로 이동 (일일알바용)

---

## 2. 전체 객실 현황판 — `/admin`

**접근 권한**: 관리자만  
**역할**: 핵심 화면. 모든 객실 상태를 한눈에 파악하고 배정

### 구성 요소

#### 상단 헤더
- 호텔명
- 현재 날짜/시간
- 로그아웃 버튼
- 네비게이션 (현황판 / 객실관리 / 직원관리 / 통계)

#### 필터 바
- 층별 필터 (전체 / 1층 / 2층 / ...)
- 상태별 필터 (전체 / 더티 / 청소중 / 완료 / 점검대기)
- 담당 직원별 필터

#### 객실 그리드
- 객실 카드 (번호, 상태, 담당 직원명, 체크인 시간)
- 상태별 색상 구분
  - 더티: 회색
  - 청소중: 노란색
  - 완료: 초록색
  - 점검대기: 보라색
  - 체크인 2시간 이내 미완료: 빨간색 테두리 + 경고 아이콘 (색맹 대응)
- 카드 클릭 → 배정 모달 열림

#### 배정 모달
- 객실 번호 / 현재 상태
- 담당 직원 선택 드롭다운 (직원 목록 + "게스트" 선택지 포함 → 게스트 풀 배정)
- 배정 확정 버튼
- 상태 수동 변경 버튼 (관리자 강제 변경용)
  - dirty → cleaning / done / inspect
  - cleaning → dirty / done / inspect
  - done → dirty (재청소 필요 시)
  - inspect → done / dirty
- 메모 입력란

#### 요약 카운터 (상단 또는 사이드)
- 더티 N개 / 청소중 N개 / 완료 N개 / 점검대기 N개

### 동작
- 실시간 상태 반영 (Supabase Realtime 구독)
- 체크인 2시간 전 자동 긴급 표시 (60초 인터벌 폴링 — 화면 마운트 시 시작, 언마운트 시 중단)

## 3. 게스트 접속 — `/guest`

**접근 권한**: 누구나 (비로그인)  
**역할**: 일일알바가 로그인 없이 당일 접속 코드만 입력해 작업 화면 진입

> **URL 형식**: `/guest?h={hotelId}`  
> `h` 파라미터(호텔 UUID)가 없으면 "잘못된 접속 링크입니다" 표시 후 진행 불가.  
> 관리자가 게스트 코드 발급 시 이 URL을 함께 표시해 일일알바에게 전달한다.

### 구성 요소
- 서비스명 / 안내 문구 ("오늘의 접속 코드를 입력하세요")
- 6자리 코드 입력 필드
- [입장] 버튼
- 에러 메시지 (코드 틀림 / 만료 / 호텔 파라미터 없음)

### 동작
- 페이지 로드 시 `?h` 파라미터 확인 → 없으면 즉시 에러 메시지 표시, 입력 폼 비활성화
- 코드 검증 성공 → 게스트 JWT 발급 → `/worker/guest` 이동
- 당일 자정 이후 코드 만료 → "오늘의 코드가 만료되었습니다. 관리자에게 문의하세요"

---

## 4. 객실 관리 — `/admin/rooms`

**접근 권한**: 관리자만  
**역할**: 초기 세팅 및 객실 추가·수정·삭제

### 구성 요소
- 객실 목록 테이블 (호수, 층, 타입, 현재 상태)
- 객실 추가 버튼 → 모달
  - 호수 입력
  - 층 입력
  - 타입 선택 (싱글 / 더블 / 스위트 / 기타)
- 객실 수정 / 삭제 버튼 (행마다)

### 동작
- 삭제 시 확인 다이얼로그
- 삭제는 **소프트 삭제** (`rooms.deleted_at = now()` 업데이트). 물리 삭제 금지
- 삭제된 객실은 현황판·목록에서 즉시 숨김 (`deleted_at IS NULL` 필터)
- room_logs·assignments 이력은 그대로 보존됨 (물리 삭제가 아니므로 CASCADE 미발동)

---

## 5. 직원 관리 — `/admin/staff`

**접근 권한**: 관리자만  
**역할**: 직원 등록, QR 발급, 삭제, 게스트 코드 발급

### 구성 요소
- 직원 목록 테이블 (이름 / 연락처 / 현재 담당 객실 수 / QR 상태)
- 직원 추가 버튼 → 모달
  - 이름 입력
  - 연락처(전화번호) 입력
  - 저장 시 QR 자동 생성
- QR 보기 / 재발급 버튼 (직원 행마다)
- 직원 삭제 버튼
- [오늘의 게스트 코드 발급] 버튼 (섹션 분리)
  - 발급 시 6자리 코드 표시 + 복사 버튼
  - 게스트 접속 URL 표시 + 복사 버튼 (`NEXT_PUBLIC_APP_URL/guest?h={hotelId}`)
  - 당일 자정 만료 안내
  - 전달 방법: 코드와 URL을 카톡 등으로 일일알바에게 전달

### 동작
- QR 보기 → QR 이미지 모달 (다운로드 가능)
- 삭제 시 확인 다이얼로그

---

## 6. 일일 통계 — `/admin/stats`

**접근 권한**: 관리자만  
**역할**: 하루 처리 현황 요약

### 구성 요소
- 날짜 선택기 (기본값: 오늘)
- 전체 완료 객실 수 / 전체 객실 수
- 직원별 완료 객실 수
- 직원별 평균 처리 시간
  - 집계 대상: `completed_at IS NOT NULL` 인 row만 (취소된 배정 제외)
  - 계산식: `AVG(completed_at - assigned_at)` per staff_id
  - 재배정 케이스에서 기존 배정은 `cancelled_at`이 기록되므로 자동 제외됨
- 미완료 객실 목록

---

## 7. 고정 직원 화면 — `/worker/[staffId]`

**접근 권한**: staffId에 해당하는 직원 (QR 링크 = JWT 세션 토큰 인증)  
**역할**: 직원이 배정된 방을 확인하고 상태 처리

### 구성 요소

#### 상단
- "안녕하세요, [이름]님" 인사
- 현재 날짜

#### 배정 목록
- 우선순위 순 정렬 (체크인 임박 방 상단)
- 객실 카드 (번호, 층, 객실 타입, 체크인 시간)
- 긴급 표시: 빨간 배지 + "긴급" 텍스트 (색맹 대응)
- 상태 버튼
  - [청소 시작] → cleaning
  - [완료] → done
  - [점검 필요] → inspect
  - [대기중으로 되돌리기] → dirty (청소 시작 실수 시 취소용, cleaning 상태일 때만 표시)

#### 메모
- 완료 처리 시 메모 입력 옵션 (선택사항)

### 동작
- 버튼 탭 → 즉시 상태 변경 + 관리자 화면 실시간 반영
- 완료된 방은 목록 하단으로 이동 또는 흐리게 처리
- 오프라인 상태 시: 마지막 배정 목록 캐시 표시 + "오프라인" 배너

---

## 8. 게스트 작업 화면 — `/worker/guest`

**접근 권한**: 당일 유효한 게스트 JWT 보유자  
**역할**: 일일알바가 게스트 풀에 배정된 방만 처리

### 구성 요소
- "게스트" 표시 (이름 없음)
- 현재 날짜
- 게스트 풀 배정 목록 (관리자가 게스트 슬롯에 배정한 방만 표시)
- 상태 버튼: [청소 시작] / [완료] / [점검 필요]
- [대기중으로 되돌리기] → dirty (cleaning 상태일 때만 표시)
- 메모 입력 (선택사항)

### 동작
- 고정 직원 화면과 동일하게 상태 변경 + 실시간 반영
- 다른 직원 배정 방, 전체 현황 접근 불가
- 당일 자정에 세션 자동 만료
